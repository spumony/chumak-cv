# План улучшений CV-сайта (на основе ресёрча)

Источник — ресёрч по эффективным CV/портфолио для Senior Frontend → AI Product
Engineer под две аудитории: **рекрутёры (EU/найм)** и **фриланс-клиенты (CIS)**.

Ограничения проекта (CLAUDE.md): статический сайт, без блога/форм отправки/бэкенда,
стек не меняем, mobile-first, токены через `@theme`, проверка через chrome-devtools MCP.

## Принципы

- Линейная архитектура сверху вниз: recruiter-flow в начале (Hero → Now → Experience),
  freelance-блок — ниже, отдельной секцией с якорем в навигации.
- Честность тиров навыков сохраняем (AI — «изучаю», не «умею»).
- EN — основной/канонический, RU — параллельный с адаптацией тона под CIS.

## Фазы

### Фаза A — Hero / позиционирование ✅ в работе

- Усилить subhead: текущая активность + явный сигнал готовности (роль + локация +
  таймзона + open to remote EU / long-term contracts).
- Сохранить AI-ключевики (LLM, RAG, evals) в pitch.

### Фаза B — Секция «Work with me» (freelance) — НОВАЯ

- Ниже Experience, перед Contact; якорь `#freelance` + пункт в nav.
- Блоки: «С чем помогаю» (2–3 ниши), «Как работаю» (формат: retainer/part-time,
  audit-спринт), «Процесс» (3–4 шага), mini-FAQ (4–6 пунктов).
- CTA: email + опциональная ссылка на звонок (Cal.com) — конфигурится в данных.
- Билингва, тон RU — прямой/экспертный без хайпа.

### Фаза C — Contact-полировка

- Кнопка «Скопировать email» (снижает friction на мобиле).
- Опциональный Telegram для RU (через данные; включить, когда будет handle).

### Фаза D — Карточка AI-проекта (Now)

- Опциональные ссылки live/repo (показывать, если заданы) + статус/дата апдейта.
- Строка «Why» — какую реальную проблему решает.

### Фаза E — Technical-SEO

- Schema.org `Person` JSON-LD в `<head>`.
- Корректный `og:image` (путь `/og.png`) + `twitter:image`.
- (Ограничение) hreflang/раздельные `/ru/` URL требуют клиентского роутинга —
  сейчас сайт one-URL с client-side i18n; вынесено в «отложено».

### Фаза F — Резюме PDF (ATS-friendly)

- Кнопка «Скачать CV» (в шапке / у Experience), показывается, если задан `resumeUrl`.
- PDF: одна колонка, без таблиц/иконок, web-safe шрифт, AI-ключевики, имя файла
  `Alexandr_Chumak_CV.pdf`. Генерация — отдельным шагом.

### Фаза G — Проверка

- `pnpm build` + `pnpm lint` зелёные.
- chrome-devtools MCP: скриншоты 320/375/768/1024, console без ошибок,
  Lighthouse (Perf ≥ 90, A11y ≥ 95).

## Отложено (нужен ввод/ассет или вне дизайн-конституции)

- **Блог / writing** — запрещён конституцией (можно пересмотреть отдельно).
- **hreflang + /ru/ URL** — нужен переход на клиентский роутинг (доп. зависимость).
- **OG-картинка (ассет 1200×630)** — мету подключаем, сам PNG генерируем отдельно.
- **Testimonials, логотипы компаний, GitHub-stats** — нужны реальные данные/согласие.
- **Cal.com / GitHub / Telegram ссылки** — нужны URL от владельца (поля опциональны).
- **PDF-бинарь** — сгенерировать и положить в `/public`.
