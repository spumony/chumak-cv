AI & Product Engineering

Rivella — multi-tenant AI booking assistant rivella.app
Next.js · TypeScript · NestJS · Prisma · PostgreSQL 16 · Docker · GitHub Actions · Telegram Bot API · YClients API
  • Built and deployed the product solo — a Next.js/TypeScript admin panel, a NestJS/Prisma API and PostgreSQL 16 — and run it in production on a VPS.
  • The assistant runs a bounded agent loop over 15 tools, capped at 8 iterations and 120 seconds per turn with a per-call timeout, an output validator in front of every reply, and a per-conversation lock so a second message cannot start a second run.
  • Retrieval is PostgreSQL full-text search over a knowledge base scoped to the tenant, with a keyword-scorer fallback — deliberately not a vector store, because the corpus is small, per-tenant and edited by hand.
  • Designed a tenant-scoped data model with non-null tenant keys across all 12 tenant-scoped tables, one bot process per tenant behind per-slug webhook routing, and a separate superadmin authentication strategy with its own table.
  • Integrated Telegram and YClients for availability, creation, rescheduling and cancellation — with a manager confirmation step and a fallback for the provider’s booking race — plus five scheduled jobs for reminders, follow-ups, no-show detection, re-engagement and a daily digest.
  • Ships continuously: GitHub Actions builds Docker images into GHCR and the VPS recreates the containers. 138 API tests pass across 12 suites, behind a 46-path OpenAPI spec.
